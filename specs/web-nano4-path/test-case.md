**規格**：`specs/web-nano4-path/plan.md`（本任務沒有 spec.md，計畫即規格，含「維護者原話」與裁決 1–12）　**總覽**：`test-case-overview.md`

自動測試檔：`platform/tests/test_web_nano4_path.py`（每條測試在註解寫明 TC 編號）。手動步驟：`docs/TESTING.md` 新增一節「國網，網頁從頭到完成」。

類型只有三種：

- **功能**：計畫說要做到的事，正常情況下做到了。
- **例外**：出錯、缺東西、使用者做了不該做的事時，系統怎麼反應（拒絕、提示、停下）。
- **不在範圍**：計畫明講這次不做、不改的事；測試確認它真的沒變。

## 共用名詞與固定測資

- 「國網環境」＝類型為 slurm、狀態 `available` 的運算環境（nano4）。「雲端環境」＝Google／AWS／Azure Batch 類、狀態 `available` 的環境。
- 「標準樣本表」＝維護者 10-29 實測用的那種：標題列 `sample,fastq_1,fastq_2,strandedness` 加 10 列資料，路徑寫 `/work/u9613010/...`（平台主機上不存在這些檔案）。
- 「上傳區」＝`<uploads_root>/<登入者>/`；樣本表存放處＝其下 `sheets/`。
- 「1 MB」＝1,048,576 位元組（沿用既有樣本表上限，裁決 6）。
- 「先看、後看」類斷言用頁面文字出現的先後位置判斷。
- 用字禁用清單（DESIGN.md「用字」）：用過、選好、寫死、自己填、自己調整、你還沒、還沒有、還不能、這個、這份、這條、這一版、一下、弄、搞、東西、喔、啦、吧、囉、蠻、超。
