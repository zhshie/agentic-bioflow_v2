# 測試案例：網頁四狀態色塊（web-status-squares）

**規格**：`specs/web-status-squares/plan.md`（本任務沒有 spec.md；需求編號 W1～W5、Q1～Q5 取自計畫本文與 2026-10-19、2026-10-22 兩次裁定）　**總覽**：`test-case-overview.md`

類型只有三種：

- **功能**：計畫說要做到的事，正常情況下做到了。
- **例外**：出現計畫沒預期的狀態或邊緣資料時，頁面怎麼反應。
- **不在範圍**：計畫明講這次不做的事；測試確認它真的沒動。

名詞（一句白話）：

- **色塊**：狀態字前面一個獨立的小方塊（網頁裡是自己一個元素，`class="sq"`），顏色由唯一的那份樣式表依狀態決定，不是字元符號。
- **四狀態**：執行中／待處理／失敗／完成（英文 Running／Pending／Failed／Done）。系統裡的狀態值仍是 running／lost／failed／succeeded，只改畫面上的字。失聯或暫停的 run 一律顯示成「待處理」。
- **狀態處**：頁面上會顯示一個 run 狀態的所有地方：①左欄 run 清單的每一列 ②右欄每一個 run 項目 ③中欄 run 頁標題旁的狀態標籤 ④「現在」頁卡片裡的每一列。
- **測試資料**：本機測試用的假 run，四種狀態各一個以上（running、lost、failed、succeeded），另有一個狀態值是「weird」的假 run 用來測未知狀態。測試不連真站台。
