## 請你判斷的三件事

1. **每條是不是你要的？** 重點看 TC-006、TC-007、TC-066：沒有你（本人）按送出，就不會有任何清理工作，也沒有任何自動路徑。
2. **有沒有漏掉的出錯情況？** 想像實驗室成員會怎麼用錯它：拿別人的申請去按、拿清理的憑證去取消或啟動別的 run、內容包被改過。這些在 TC-009、TC-014、TC-015、TC-044 到 TC-050。
3. **「不在範圍」對嗎？** 本片只讓平台「會處理」清理，沒有任何程式會真的建立清理申請，也沒有網頁畫面（TC-065、TC-074）；刪檔的代理程式在 c、d 片；建立申請在 f 片。
