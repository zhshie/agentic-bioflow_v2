1. **每條是不是你要的？** 重點是 TC-002（守門測試現在要紅）、TC-020（既有斷言的比對字串一個都沒動）、TC-031（壓測改後 0 次）、TC-037（全套綠）。

## 我（撰寫者）不確定的地方

1. 註解和字串資料要不要算違規？`tests/constitution_scope_test.sh:24` 是註解、`tests/no_second_run_state_test.sh:238` 是餵給偵測器的字串，兩處都含 `| grep -q`。計畫沒說守門測試要不要略過它們。（合約寫成兩種做法都過：TC-028、TC-029 只要求案例與結果不變。）
2. 壓測的「8 份同時」是 8 份各自獨立的副本，還是同一個資料夾？（CLAUDE.md 說同一個 checkout 同時跑兩次會互相弄壞暫存。合約只要求 ledger 寫明，見 TC-030／031。）
3. 「處」要以 grep 出現次數算，還是以行數算？（例：`tests/guard_plugin_files_test.sh:258` 同一行有兩個。合約只要求 ledger 寫明算法、與 diff 一致，見 TC-026。）
4. 「`|` 在行尾、grep 在下一行」的寫法，守門測試不處理（計畫沒提），目前 `tests/` 裡也沒有這種寫法。這樣可以嗎？
5. `grep --quiet`／`--silent` 的長寫法計畫沒提，目前 `pipefail` 的檔裡沒有，所以不出題。
