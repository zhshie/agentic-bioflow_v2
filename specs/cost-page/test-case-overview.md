## 我（撰寫者）不確定的地方

- 計畫自己的選擇與 DESIGN「States」不同：費用表把執行中標成「⟳ 執行中」（DESIGN 的分析狀態用「▶」），而且 lost（失聯）的分析在這張表也標成執行中（DESIGN 說 lost 顯示為 Failed）。TC 照計畫字面寫（TC-026、028）。這樣對嗎？
- 計畫範圍列了 `platform/abf_platform/static/*.css`，但這個資料夾不存在；唯一的樣式表是 `web_board.py` 裡的 `STYLE`，而裁決 7 又不准動 `web_board.py` 除了 `_mast` 與兩個字串。裁決 5 允許的「數字欄靠右、狀態符號」樣式因此沒有可放的地方。沒有任何 TC 要求這兩項樣式，所以不擋；要不要做、放哪，請 developer-agent 決定。
- 剩餘為 0 的卡片，計畫只說「用既有需處理樣式」，沒說卡上寫什麼字、用什麼符號。TC-017 只要求「有一個符號加一個文字、不只靠顏色」。想指定確切用語嗎？
- 計畫把「國網 SU」的算不出原因直接放進卡內小字，但這些原因字串本身是中英夾雜（例如「run 還沒結束，SU 等它結束後再算 (the run has not ended)」）。TC-005 要求中文頁看得到原因，TC-058 要求英文頁沒有中文字，所以英文頁得只取英文那半。這樣合理嗎？
- `su.month_total` 只回數字或 None、沒有原因；計畫卻要 `su.unknown_reasons` 帶原因，執行者得自己逐個分析去收原因。TC-074 只檢查結果，不管做法。
- 執行中的雲端分析：`month_used` 會把它目前累積的費用算進「已用」，但表裡該列顯示「—」，所以表加總可能小於已用卡。TC 沒有要求兩者相等。這是你要的嗎？
- `?month=` 給了未來的月份或不存在的月份（如 2099-01、2026-13）時要怎麼處理，計畫沒寫；TC 只涵蓋 `abc` 這種格式錯。
- 金額格式：計畫寫「US$ 12.34」（有空格），既有 `cloud_cost._money` 是「US$12.34」（沒空格）。TC 照計畫（有空格）。
- 表裡「在哪裡跑」為「—」的情況（TC-025）要怎麼在測試中造出一個「平台送出但判斷不出運算環境」的分析，計畫沒說；留給執行者決定做法。
