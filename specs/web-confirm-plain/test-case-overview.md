## 我（撰寫者）不確定的地方

1. 計畫 C1 把「刪除保留內容」列為請求種類，但目前確認頁（`/c/`）只有 launch 與 cancel 兩種申請，刪除只走終端機或 MCP 表單，沒有頁面。我沒有寫這種種類的 TC（也不要求實作新頁面，見 TC-032）。這樣可以嗎，還是要把這一項從計畫刪掉？
2. 「新資料夾（有的話）」：我只要求重跑（TC-002）一定顯示。送出新分析其實也有「專屬資料夾」、續跑則是沿用舊資料夾；這兩種要不要也顯示？目前不檢查、也不禁止。
3. 英文版我只檢查標籤與摘要標題（TC-021、022）；種類名稱（送出新分析／續跑／重跑／取消）和頁首說明句是否也要英文，計畫沒寫，沒有檢查。
4. 頁首那句「下面就是會被送出的全部內容…」在內容折疊後是否要改寫，計畫沒寫，沒有檢查；實作者改動它不算違規，但維護者看 TC-007 時請順便留意讀起來通不通。
5. 「看得出沒寫的欄位就省略」與原則 IV.9「缺口要明寫」的關係：我把它限定在白話區塊（完整內容仍在摺疊區內一字不少），所以不衝突；若你要白話區塊也明寫「查不到」，要改計畫。
