## 請你判斷的三件事

1. **每條是不是你要的？** 重點是兩句話：續跑中的分析取消不該被拒（TC-001、002）；不是這個 run 的資料夾仍要拒（TC-007～013）。
2. **有沒有漏掉的出錯情況？** 想像實驗室成員會怎麼用錯它：用別人的資料夾、亂寫續跑編號、塞 `..`。
3. **「不在範圍」對嗎？** Google Batch 的取消、取消內容包的組法、錯誤訊息文字、資料庫都不動。
