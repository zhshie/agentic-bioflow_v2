## 請你判斷的三件事

1. **每條是不是你要的？** 重點看 TC-OI03／OI11（真目錄的 samtools_sort：輸入 1 是警告、輸入 2 `index_format` 是錯誤）與 TC-OI12／OI13（只有 meta 記錄的通道、沒有 optional 欄位的通道，都不算必填）。這幾條照計畫「裁決二」寫。
2. **有沒有漏掉的出錯情況？** 想像上游把 optional 寫成奇怪的值（文字 "true"、null）：計畫只說「明確為 false 才算必填」，本合約沒有另外出題（見下）。
3. **「不在範圍」對嗎？** 不改其他 code 的規則、不改儲存格式、不改 017b、不需要 migration、不動範圍外的檔案。

## 我（撰寫者）不確定的地方

- 計畫的「目標」段落仍寫「只要有一筆 `optional: false`」，與「裁決二」（不看 meta 記錄）不同；計畫已註明裁決二取代目標句，本合約全照裁決二。這只是請你知道，不阻擋。
- 目錄裡 `optional` 若是 null 或字串（不是布林）要算必填嗎？計畫只說「明確為 `false`」才算，本合約不另出題；真目錄的值都是布林，需要的話請告訴我補一條。
- 同一次檢查裡 error 的 `OPEN_INPUT` 排在 warning 之前，是靠既有排序規則（TC-OI36 的既有測試不修改而通過），本合約沒有為它另寫新斷言。
