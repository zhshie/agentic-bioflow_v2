## 請你判斷的三件事

1. **每條是不是你要的？** 表格要有七種資料、每一格的「存多久」都有出處；沒有規則就寫 `no automatic deletion`，不能編期限。
2. **有沒有漏掉的出錯情況？** 想像之後有人再加一個要 ask 的工具、或改了保留天數，但文件沒跟著改：TC-016、017、020 就是要讓這種漂移被測試抓到。
3. **「不在範圍」對嗎？** 不改程式、不改 CHANGELOG 與其他文件、網頁與客戶端「第一次顯示揭露文字」這次不做，只在文件裡標「還沒做」。
