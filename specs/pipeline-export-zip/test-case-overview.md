1. **每條是不是你要的？** 有沒有哪條的「預期結果」跟你想的不一樣。

## 我（撰寫者）不確定的地方

1. 計畫說「走 `build_project` 的同一套上限」，但 `build_project` 需要樣本表欄名，還會改寫 `main.nf`、在設定檔後附加 PUBLISH。我照「重用 `render_pipeline` 的檔案」出題：zip 內三個專案檔與 `render_pipeline` 逐字相同（TC-004），上限只共用 `pipeline_launch` 的 `MAX_BYTES` 與 `MAX_FILES`（TC-029）。這樣對嗎？
2. zip 內說明檔（裁決 2）的檔名與格式計畫沒定，TC-009 只檢查「有一份、文字含每個未填輸入的名稱」。要不要指定檔名（例如 `README.txt`）？
3. 沒驗證過時，回應的 `validation` 欄是不存在還是空值，計畫沒說；TC-014 只要求匯出成功。
4. pipeline 名稱含空白、斜線或中文時，`filename` 要不要處理？TC-003 只用普通名稱，這種情況這次不測。
5. TC-043、044、045 標手動，因為 `docs/TESTING.md` 沒有對應步驟。要由驗收者直接讀 diff 與 ledger，可以嗎？

以上五點都不改變「檢查什麼」，所以不擋合約。
