## 請你判斷的三件事

1. **每條是不是你要的？** 特別是 TC-007：文件要把 `wsl --shutdown` 的後果寫明（WSL 裡全部停、國網連線斷、要重新輸入 OTP），這跟你昨天同意的一致嗎。
2. **有沒有漏掉的出錯情況？** 例如：權杖檔錯了時，它停下並在記錄裡說原因（TC-019），而不是每五秒默默重試。
3. **「不在範圍」對嗎？** 這次不處理國網連線自動恢復、Funnel、你桌機上的任何實際更動、自寫看守腳本（PR #391 保持草稿）。

## 我（撰寫者）不確定的地方

1. 站台 unit 只帶 `NoNewPrivileges=true`、不帶 `PrivateTmp`，這對 agent 沒影響，我有把握但沒在機器上跑過；TC-020 是真正的證明，請你在桌機上做。
2. WSL 在「只有 systemd 服務、沒有任何 wsl.exe 用戶端」時會不會被關掉，我憑已知行為判斷會，所以需要保活工作；到底夠不夠只有你的桌機能證明（TC-012）。
3. `loginctl enable-linger` 在你的 WSL 裡要不要 sudo，我不確定；文件要照實寫，TC-013 請你回報實際情況。
4. 你的桌機是 Windows 10（19045）；`systemd=true` 要新版 WSL（`wsl --update`），TC-013 會看到版本夠不夠。
