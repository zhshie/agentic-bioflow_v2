## 請你判斷的三件事

1. **每條是不是你要的？** 特別看 TC-062（送出畫面第一段那句費用說明）、TC-065（畫面上不出現任何金額）、TC-098（Google Batch 環境不會被自動選到，要明講環境名字）。
2. **有沒有漏掉的出錯情況？** 想像實驗室成員會怎麼用錯它：samplesheet 放本機路徑（TC-053）、忘了裝 Java／Nextflow（TC-020、TC-021）、金鑰檔權限太開（TC-087）、對別人的 run 按取消（TC-101）。
3. **「不在範圍」對嗎？** 這次不做：費用估價與上限、本機檔案上傳、續跑／原樣重跑、刪 work、自動刪除 Batch 工作、網頁新畫面。取消只送一次 SIGTERM，殘留的 Batch 工作要你自己去 Console 確認。
