## 我（撰寫者）不確定的地方

1. 右欄 launch、downstream、finished 三個群組的標題要顯示「0」還是「—」？計畫只說「五個群組附計數」，所以測試只釘 running 與 results 的數字（TC-H22b），三個預留群組只釘「有出現」（TC-H22a）。
2. 選到的 run 如果排在左欄前 100 筆之外，中欄還要顯示它嗎？計畫沒說，測試沒釘。
3. 登入頁、確認頁、404 頁是否與 `/` 共用同一份樣式表？計畫說 CSP 只有「一份固定樣式表」的雜湊，TC-H13d 假設每一頁的雜湊都和該頁樣式表一致；若實作用兩份樣式表，需要回來改計畫。
4. 「設定（尚未開放）」是純文字、不是連結，對嗎？計畫只寫「尚未開放」，TC-H20d 照此釘成「沒有通往設定功能的連結或表單」。
5. 五個階段在畫面上的中文名稱計畫沒給，測試用網址的 `?stage=` 名稱與箭頭連結來驗證，不釘中文階段名。
6. 計畫開頭寫「#116 合併後才開工」。#116 已在 v3 歷史中（合併提交 a9f6481），條件已滿足；實作時請重查計畫引用的行號。
