## 請你判斷的三件事

1. **每條是不是你要的？** 有沒有哪條的「預期結果」跟你想的不一樣。你最該對照的是「給維護者」三點與你選的版面 B：TC-L01 至 TC-L06（頂欄、三欄、左欄）、TC-L07 至 TC-L16（中欄五階段板）、TC-L17 至 TC-L30（右欄費用行與整塊項目）、TC-L31 至 TC-L44（中英切換）、TC-H03a 至 TC-H04c 與 TC-H11a（只看自己的、只能看），以及人工看圖的 TC-V06 至 TC-V10。
2. **有沒有漏掉的出錯情況？** 想像實驗室成員會怎麼用錯它。
3. **「不在範圍」對嗎？** 這次不做的事，有沒有其實這次就該做的。特別是 TC-N08（登入頁與確認頁這次不翻成英文）和 TC-N10（聊天框、分頁、上傳都不做）。

## 我（撰寫者）不確定的地方

1. 左欄標題沿用「我的 run」，對嗎？L2 只說「一個誠實的標題」，決策 6 的「我的 run」沒有被裁定取代，所以 TC-L02、TC-L05 照釘。
2. 階段條五格的中文名（送出、執行中、結果、下游、完成）取自裁定 B5 的群組名，計畫沒有直接列階段條的標籤。TC-L07 照此釘；若你要的名字不同，改這一條。
3. 階段條的格子本身要不要是連結？計畫只明講上一階段與下一階段是連結，所以測試只釘那兩個連結，不釘格子。
4. 選到的階段不是該 run 自己的階段（例如成功的 run 看 `?stage=running`）時，中欄顯示什麼？計畫沒說，測試只釘「被接受、所選格子帶 `aria-current`、回 200」，不釘內容。
5. 兩個 run 開始時間相同、或沒有開始時間時，序號與排序怎麼定？計畫沒說，TC-L22、TC-L30 都用各不相同的開始時間。
6. 英文版的文字只釘了七格標籤（裁定 C6）與「reason not recorded」，其餘只釘「除語言名『中』外沒有任何中文字」（TC-L32）。英文措辭由執行者決定，你要在 TC-V08 的截圖裡看它讀不讀得通。
7. `?lang=` 給 `en` 以外的值時當作中文，是我從「預設中文」推出來的（TC-L41）。這在計畫裡沒有一句明講。
8. 「任何頁面都不含 http 網址」（L8）這裡只管看板頁、404 頁、空狀態頁（TC-L44）；登入頁與同意頁因為會依連線的客戶端調整 `form-action`，沒有納入。
9. 時間的顯示格式計畫沒定（參考稿是「10-18 08:12」），測試寫死一個已知時間在現行格式下的字串，所以格式可以選，但選了就不能在測試和頁面之間不一致。
10. 計畫的 Tests 與 Design decisions 還留著被 B1／B4／B5／C1 蓋掉的舊字樣（兩行費用、五個群組、「專案與分析（011b）尚未開放」）。C2 已寫明新裁定優先，不影響本合約，但建議 developer-agent 之後把舊字樣清掉，免得有人誤讀。
