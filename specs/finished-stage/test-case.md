# 測試案例：完成階段第一刀（來源紀錄＋交付包清單）

**規格**：`specs/finished-stage/plan.md`（沒有 spec.md）　**總覽**：`test-case-overview.md`

名詞：「完成階段」＝網頁上 `?run=<id>&stage=finished` 這一頁；「來源紀錄」＝這次分析是怎麼跑的；「交付包」＝要交給別人的東西清單；「中間欄」＝頁面中間放內容的那一欄；「灰字『之後開放』」＝不是連結、不是按鈕的灰色文字。

類型只有三種：

- **功能**：計畫說要做到的事，正常情況下做到了。
- **例外**：出錯、缺東西、不該進來的人或狀態，系統怎麼反應。
- **不在範圍**：計畫明講這次不做的事；測試確認它真的沒做。
