## 請你判斷的三件事

1. **每條是不是你要的？** 特別看 US1：你的兩句原話（「我的 run」「還沒有 run。」；「選用這個樣本」「用過的」）有沒有在每個頁面都被測到。
2. **有沒有漏掉的出錯情況？** 計畫列的頁面都有對應；如果你還看過別的口語畫面，現在說，因為這次的守衛只管計畫列的頁面和字串表。
3. **「不在範圍」對嗎？** 雙語並列頁（登入、/welcome、授權頁）這次不改成單語；`confirm.py` 只改看板會顯示的那一句；其他 action 層訊息只記在 ledger「後續」。
