## 我（撰寫者）不確定的地方

1. 級別列字面：DESIGN.md 寫「! 需要你處理」，裁決 2 改為既有的「待處理」。TC 照裁決 2。要不要回頭改 DESIGN.md 是你的決定，不影響這一輪的檢查。
2. 失敗頁標題列仍有 續跑／重跑／取消 三顆（計畫稱「run 選單」），右欄才是唯一一顆主按鈕。這符合你「直接告訴使用者要做甚麼，不是讓他們選」嗎？TC 照計畫，只要求右欄恰一顆。
3. 時間顯示：計畫寫 `HH:MM`，現有函式輸出 `MM-DD HH:MM`。TC 兩種都接受。
4. 空狀態的右欄放 `—` 還是「目前沒有待處理的事」，計畫兩處寫法不同。TC-080 只要求有標頭與 `—`、沒有按鈕與 run 名。
5. 英文字樣計畫只給了一部分；其餘 TC 只要求「整頁沒有中文字元」。
6. 8 條手動驗證（截圖與 diff 核對）因為裁決 8 不動 `docs/TESTING.md`，沒有 TESTING.md 的步驟可對照，閱卷時靠 PR 截圖與 `git diff`。
