白話說這份合約在驗什麼：登記一份資料集時可以指定「放在實驗室自己的 Google Cloud bucket」；位置只能落在你自己的前綴、且 bucket 必須就是你那個計算環境的 workDir 的 bucket；別人的位置、別人的環境、像憑證的值一律白話拒絕；單檔超過 2 GB 就給一行在你電腦上跑的指令；以及一個不落地、一塊一塊轉交的串流核心。真正把檔案從瀏覽器傳進 bucket 的管道這次不做。

2026-10-24 修訂（計畫新增「裁決三」，developer-agent 重新開啟合約）：①改動範圍多了 `platform/tests/test_gcb_ce.py`，且只准動一處（把 `storage cp` 從「後面的切片還不存在」那條 regex 拿掉）→ 改寫 TC-083、TC-084，新增 TC-097、TC-098；②`storage cp` 只准出現在 `cloud_store.py`、該檔不得有能啟動程式的東西 → 新增 TC-099、TC-100；③不准拆字串繞過掃描 → 新增 TC-101、TC-102。其餘 96 條的編號與內容沒動。
