## 我（撰寫者）不確定的地方

1. 計畫要求「0 skipped」，但 `tests/platform_test.sh` 在沒有 Java 等環境時（非 CI）會略過端到端測試。本機若缺環境，要在 WSL 裝齊再跑，還是接受以 CI 結果為準？（不影響測試案例的內容，只影響在哪裡驗收。）
2. 手動案例（TC-003、005、006、010–014、C01）的步驟是驗收審查者看差異與在舊／新 helper 各跑一次；計畫把 `docs/` 列為範圍外，所以不會再為它們在 `docs/TESTING.md` 加步驟。這樣可以嗎？
