## 我（撰寫者）不確定的地方

1. 計畫第 3 項測試說「repo path in backticks … contains '/' and an extension」，但第 4 節又要求文件寫出真實的執行期路徑（如 `~/.local/share/abf-platform/index.db`），這類路徑同樣含斜線與副檔名卻不在倉庫裡。TC-024 把「倉庫路徑」定為以倉庫頂層目錄開頭的路徑；這樣讀對嗎？（我認為是計畫的本意，否則第 4 節與測試互相矛盾。）
2. 第 6 節（Not built yet）也在 `abf-platform <子指令>` 的檢查範圍內，所以那一節不能用 `` `abf-platform 某個不存在的指令` `` 的寫法，只能用文字描述。這是計畫測試的必然結果，不是額外要求；要不要接受？
3. `ce primary`、`ce disable`、`ce enable` 在 `cli.py` 是用迴圈建立的，不是字面的 `add_parser("primary")`。TC-022 要求測試不得因此誤判；若執行者只解析字面名稱，文件就得避開這三個指令，這會讓文件少講真實存在的指令。我選擇要求測試處理它們。

以上三點都不改變「檢查什麼」的方向，只是執行細節的取捨，故不擋合約。
