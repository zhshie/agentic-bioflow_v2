## 請你判斷的三件事

1. **每條是不是你要的？** 特別看兩條：
   - TC-005：超過心跳間隔 3 倍沒有消息，就顯示「失聯」；之後收到結束訊息，會改回成功或失敗。
   - TC-034：被強制中止的 run，重建後顯示「失聯」。
2. **有沒有漏掉的出錯情況？** 想像實驗室成員會怎麼用錯它，例如：
   - 把 token 寫進 config；
   - 把平台開放給整個網路；
   - 重建時指到不存在的資料夾。
3. **「不在範圍」對嗎？** 這次不做的有：寫入動作、站台代理、多人與網頁、修憲、改現有 plugin。其中有沒有其實這次就該做的？
