## 我（撰寫者）不確定的地方

這些計畫沒說，所以**沒有**出題；你回一句話即可，不影響已出的案例。

1. 任務條的「填滿規則」計畫沒寫。我只釘「條存在」與「總數 0 時是空的」（Q6），沒有釘總數大於 0 時填多少。要不要沿用 011a 的「(成功 + 快取) ÷ 總數」？
2. 失聯（lost）的 run 沒有結束時間，「耗時」算到「現在」還是算到最後一次心跳？計畫寫「start → now or end」，我沒有為 lost 出題。
3. 選了一個「成功」的 run 並手動加 `&stage=running`，頁面要顯示執行中階段頁還是 011a 的占位？計畫只說「for the selected run」。我只釘 failed、lost、running 三種。
4. 011a 在選到失敗 run 的中欄有一個完整失敗原因的灰底區塊（R10：「詳情保留完整原因」）。011b 是否保留？我沒有釘「保留」或「移除」；如果執行者移除了，要在帳本記一列（TC-D01 會檢查）。
5. 「現在」頁需要注意卡一次最多放幾個通知，計畫沒說；我沿用 011a 的 100 筆上限與「還有 N 筆」（TC-R35）。每個失敗 run 的通知要多呼叫一次取失敗任務（最多 100 次）；效能不出題。
6. 「等 N 項」我解讀為「其餘還有 N 個」（三個在跑 → 第一個加「等 2 項」／「+2 more」）。如果你要的是總數，請說。
7. 耗時超過一天、或整點（例如 2 小時 0 分）的寫法計畫沒說，沒有出題；只釘計畫給的「2 小時 5 分」「2h 5m」、「不到 1 分」「<1m」。
8. 通知的「分析名稱用等寬字型」（TC-R02）我以樣式表有 `ui-monospace` 那一組來檢查；若執行者用別的做法達到同樣外觀，這條需要微調措辭，但不影響意義。
9. 欄位名稱「名稱／結束代碼／錯誤訊息／工作目錄」與執行資訊的欄位名稱，計畫沒有給中英文字；案例只要求「欄位名與值成對」與英文版沒有 CJK 字元，不釘具體用字。
