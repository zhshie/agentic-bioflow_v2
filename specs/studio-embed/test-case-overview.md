## 我（撰寫者）不確定的地方

這些都不改變要檢查的事，不擋合約：

1. 結尾多一個 `/` 的位址（`http://127.0.0.1:8790/`）要拒絕還是正規化？計畫說「沒有路徑」；TC-003 兩種都接受，只要求絕不把帶路徑的字串送進 CSP 或 iframe。建議拒絕。
2. 設定有填時，今天的「貼上自己 Studio 網址」表單要不要保留？計畫沒說。TC-009 只要求 iframe 永遠只用設定值。
3. 設定的範例埠：RStudio 預設 8787 會與平台自己的 `abf-serve`（8787）相撞，TC-032 禁止 8787～8789，實際用哪個埠由實作者在範例中選。
4. 第二行 R 指令怎麼把目前的圖變成檔案，計畫沒寫；TC-028 只要求只用基本 R、存暫存 png、再送出。
5. ADR 0010 的後果寫「三項試驗要在依賴它們的程式之前」。本計畫是同日建置加桌機試驗；TC-036～TC-040 與 ledger 當作第三項試驗的書面結果。若你要求試驗先於合併寫成報告，請說。
6. RStudio 的下列行為從套件無法驗證，只能靠人工 TC-036～TC-040：`www-address` 預設值、`www-frame-origin` 的值格式、非 root 時 `auth-none` 是否生效、非 root 是否需要把資料目錄指到家目錄、跨站 iframe 是否需要 `www-same-site=none`、`allow` 屬性要寫哪個字、https 頁面嵌 `http://127.0.0.1` 在各瀏覽器的處理。
