## 我（撰寫者）不確定的地方

- 計畫對新案例只寫「斷言 rc 2」。我多要求了輸出含 `no run area known`（TC-008），因為腳本裡還有別的結束碼 2 的拒絕路徑，只看 rc 2 可能因為別的原因而綠。這樣可以嗎？
- 計畫舉例的不可寫路徑是 `/work/...`。若測試在 root 身分（例如某些容器）下執行，`mkdir /work` 會成功，舊寫法就不會是 rc 1，新案例也就分不出有沒有隔離。TC-009 因此要求夾具用「連 root 也建不出來」的路徑（例如放在一個普通檔案底下）。這是對計畫的小補強，不是阻擋項目。
- TC-010、014、015、016 沒有對應的測試檔或 `docs/TESTING.md` 步驟，是閱卷時用 `git diff` 與讀檔核對的項目。範本只允許「自動」「手動」兩種，我歸為手動，請確認這樣接受。
