# 測試案例：站台代理＋算力環境（第一片：連線、算力環境、唯讀工作）

**規格**：`specs/007-station-agent/spec.md`　**總覽**：`test-case-overview.md`

類型只有三種：

- **功能**：規格說要做到的事，在正常情況下有做到。
- **例外**：出錯、缺東西，或使用者、平台做了不該做的事時，系統怎麼反應（拒絕、提示、停下）。
- **不在範圍**：規格明講這次不做的事。測試確認它真的沒做，或會明白說「這個不支援」，而不是悄悄亂做。

## 名詞

- **真代理**：以子行程執行的 `abf-station run`，不是在測試行程裡直接呼叫函式。
- **假站台**：測試建的暫存部署資料夾。
  - `env.yaml` 設 `reach: local`，或設 `reach: ssh` 加 `site_host`，並用 `ON_SITE_SSH_BIN` 指向測試自己的假 ssh。
  - 裡面有 `rawdata/`、`results/`、`analysis/` 和一個工作資料夾。
  - PATH 最前面放假的 `sbatch`、`squeue`、`sinfo`、`java`、`nextflow`、`scancel`、`srun`、`qsub`。每次被呼叫，都把完整參數追加寫進紀錄檔。
- **危險呼叫**：紀錄檔裡出現下列任何一種：
  - `sbatch`、`srun`、`qsub` 帶腳本檔或 `--wrap`；
  - `nextflow` 帶 `run`；
  - 任何一次 `scancel`。
- **守衛檔**：假站台的 `rawdata/`、`results/`、`analysis/` 各放一個內容固定的檔案。測試記下內容雜湊與修改時間，事後必須完全相同。
- **假平台**：測試自己寫的小伺服器，只講代理協定。它可以回任何測試想給的工作，用來把惡意或畸形的工作交給真代理，並數代理送了幾次請求。
- **H**：代理的心跳間隔，目前是 20 秒。數值讀自程式常數，並且必須與 `docs/PLATFORM.md` 寫的相同。**離線門檻**是 3H。
- **輪詢時間**：一次長輪詢最久等多久，目前是 25 秒。測試可以用 `docs/PLATFORM.md` 記載的設定縮短它。
- **等待時間**：呼叫端（MCP 或命令列）等一個工作結果的上限，依工作種類而定。同樣可以用文件記載的設定縮短。
- **資料庫位元組**：平台所有資料庫檔（索引、token、算力環境與代理的檔案），連同 `-wal`、`-shm`、`-journal` 的全部內容。
- **canary**：測試故意塞進去的假秘密字串。事後要確認它沒被存下、沒被回傳、沒被印出。
- **讀取範圍**：代理允許列出的位置，包含該環境的工作資料夾、啟動資料夾，以及部署設定或環境設定指定的額外讀取位置（例如 rawdata 所在處）。
- **真平台行程**：以 `abf-platform serve` 啟動、監聽 127.0.0.1 的獨立行程。

所有「自動」案例都由 `tests/platform_test.sh` 一併執行。驗證方式的寫法：

- 「自動：e2e」＝真代理、真平台行程、假站台一起跑。
- 「自動：假平台」＝真代理連到假平台。
