## 請你判斷的三件事

1. **「離線」和「還沒預檢」的樣子對不對？**
   - 代理超過心跳間隔 3 倍沒消息，就顯示「離線」（TC-002、TC-003）。
   - 代理忙著預檢時，不能被當成離線（TC-023）。
   - 建立環境時若沒有代理在線，環境會停在「建立中」並寫明原因（TC-026）。
2. **13 種雲端種類「接受設定、但不能用」夠不夠？**
   - 只有 Slurm 能預檢與列檔。
   - 其他種類可以建立，但狀態固定是「尚未支援」：預檢與列檔立刻被拒，也不能設為主要（TC-030、TC-031、TC-096、TC-085）。
3. **列出檔案的揭露與安全邊界。**
   - 檔名、大小、修改時間會傳給平台，再傳給你選的模型（TC-075）。
   - 連非本機的平台只用 HTTPS（TC-021）。
   - token 檔必須是 0600，而且不能放在 Windows 磁碟上（TC-068、TC-097）。
   - 刪除、搬移、`scancel`、寫入 rawdata／results／analysis、不認得的工作，一律被拒絕（TC-060～064）。
