## 請你判斷的三件事

1. **每條是不是你要的？** 特別是 TC-018：加網域時**一定要寫原因**才准寫入——會不會太囉唆？
2. **有沒有漏掉的出錯情況？** 想像實驗室成員碰到被擋的網域時會怎麼亂來。
3. **「不在範圍」對嗎？** 加進 plugin 內建清單仍然要找維護者；只准計算節點連進中繼程式的限制不動。

## 我（撰寫者）不確定的地方

1. **原因要強制填嗎？**（TC-018）我建議要：放行網域是移動安全邊界，半年後要能查到為什麼。原因可以很短，例如「nf-core/xxx 失敗 run 3a8f」。
2. **重啟中繼程式要不要也問你？** 現在的安全網對「啟動／停止中繼程式」本來就會跳確認（共用登入節點上的程式），所以加網域之後的重啟會再問一次。我建議維持——兩次確認各自保護不同的事。
