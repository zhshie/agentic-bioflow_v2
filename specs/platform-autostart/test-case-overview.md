## 手動驗證要做什麼（你不用讀程式碼）

這八條都要在你的桌機、跟你約好時間才做，這個 PR 本身不會碰你的桌機。執行者要把每一條的步驟寫進 `docs/TESTING.md` 的「platform-autostart」一節，寫到能照著做。你要看的是：
- 重開機登入後什麼都不做，網站會不會好（TC-013、TC-015）。
- 你把其中一個行程砍掉，幾秒後會不會回來、其他的有沒有被動到（TC-034）。
- 打一個指令看得到現在哪些在跑，而且你看得懂（TC-047）。
- 手動再開一次，它會不會說「已經有一份在跑」（TC-055）。
- 工作排程器裡看得到、也移除得掉那個登入工作，而且全程沒跳出系統管理員提示（TC-014）。
- 看守腳本的清單與記錄裡沒有你的權杖（TC-077）。
- 合併前你的桌機沒被動過（TC-114）。

## 請你判斷的三件事

1. **每條是不是你要的？** 有沒有哪條的「預期結果」跟你想的不一樣。
2. **有沒有漏掉的出錯情況？** 想像實驗室成員會怎麼用錯它。
3. **「不在範圍」對嗎？** 這次不做的事，有沒有其實這次就該做的。

## 我（撰寫者）不確定的地方

每條都已依建議答案寫進案例；你一句話回答即可，答得不一樣我就改對應案例。

- P1 看守腳本算不算憲法 I.2 禁止的「監控常駐程式」？建議：不算，它只看自己啟動的行程、不看任何 run 的狀態，放在 `deploy/`。（TC-121）
- P2 清單每行的指令用 `bash -c "exec …"` 執行、引號照 shell 規則？建議：是；`--check` 只檢查第一個字存在且可執行。（TC-080、TC-084）
- P3 測試用的旋鈕（狀態資料夾、間隔底／頂、穩定秒數、等待秒數、換檔大小）由執行者命名並寫在檔頭？建議：是，預設仍是 2／60／30／10 秒／10 MB。（TC-027、TC-093）
- P4 登入工作要加「電池供電也啟動、已有一份在跑就忽略新的、視窗隱藏」嗎？建議：要。（TC-009）
- P5 Windows PowerShell 5.1 會把無 BOM 的中文讀亂：`.ps1` 存帶 BOM 的 UTF-8 或訊息全用 ASCII？建議：兩者擇一。（TC-010）
- P6 安裝腳本用 `-Distro`、`-User`、`-Script` 三個參數，沒給的 distro 與使用者用預設，腳本路徑沒給就停手說明？建議：是。（TC-003）
- P7 清單是空的就拒絕（結束碼 2）？建議：是。（TC-089）
- P8 行程跑著時記錄也要換檔（不只在啟動時）？建議：是，否則不當掉的平台記錄會無限長。（TC-092）
- P9 看守腳本被 `kill -9` 時子行程會成孤兒、重啟後重複起一份：只在文件警告、不做額外機制？建議：是。（TC-053、TC-098）
- P10 清單檔 0644（群組、其他人可讀）也拒絕，訊息附 `chmod 600`？建議：照計畫，是。（TC-069）
- P11 `--status` 看守腳本在跑就結束碼 0（即使某行程剛好沒在跑）；沒在跑才是 1？建議：是。（TC-040、TC-042、TC-044）
- P12 所有「拒絕啟動」的情況結束碼都是 2；只有「第二份被鎖擋下」是 0？建議：是。（TC-050、TC-063、TC-069、TC-082）
- P13 權杖偵測看所有行（含註解）、`abf_` 後要連續 20 個以上英數字才算（與平台自己的形狀一致）？建議：是。（TC-066、TC-068）
