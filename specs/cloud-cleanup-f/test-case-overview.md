## 請你判斷的三件事

1. **每條是不是你要的？** 最該看的是 TC-021～TC-027：確認畫面逐字要有的三句話（①永久刪除 work 資料夾、②結果與原始資料與分析不會被動、③刪掉之後這個 run 不能再續跑）、以及 Google Batch 才有的 bucket 句與軟刪除說明。這幾句合併前還會附截圖給你回好／不好（TC-102）。
2. **有沒有漏掉的出錯情況？** 想像你自己的 run：失敗的、跑到一半的、續跑成功的、別人送出的、環境之後改過路徑的。清單裡每一種都有對應的條目（TC-009～TC-019、TC-038～TC-048）。
3. **「不在範圍」對嗎？** 這次不做：30 天到期前提醒與儲存月費、過去已成功的 run 補提、逾時後重提、失敗的 run 清理、批次清／部分清、自動刪、新的工具／網頁／指令。
