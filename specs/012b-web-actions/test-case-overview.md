## 我（撰寫者）不確定的地方

這些我沒有自己猜答案；測試寫的是計畫有講的行為。請在實作開始前、或在驗收時用一句話回答。

1. 計畫說狀態用「小色塊＋文字」且新標記不用符號，但 DESIGN.md 與 ui 守則寫「符號＋文字＋顏色」三者並用。我把「色塊是獨立標記元素」當成符合你的新要求（TC-044）。這樣可以嗎？
