## 我（撰寫者）不確定的地方

1. 計畫的「對應案例」寫「恢復後同一申請可重新送出（R3）」，但作法 (3) 與測試 13 是「申請被標為 void，使用者重新呼叫 launch 後成功入列」。我依後者出題（TC-052）；若你要的是「同一張已 void 的申請本身能再按 yes」，請告訴我。
2. 計畫沒有說明 `keepalive_log.sh` 在 `ABF_KEEPALIVE_ONCE=1` 之外，「連續兩輪」的狀態（上一輪是 open）要靠記憶體還是靠 log 檔延續。TC-064～TC-065 只規定可觀察結果（第二輪寫出 `event=closed`／`event=reopened`），不規定做法。
3. TC-032 沒有核可草稿可比對（裁決 5 說明以 `DESIGN.md` 為依據），所以只能由你合併後看截圖；你回「不好」就另開修正件，不影響本件通過。
4. `tests/keepalive_log_test.sh` 是否由 `tests/run_all.sh` 自動帶起，計畫沒寫；TC-083 要求它在完整 shell 測試中被執行，若現行 `run_all.sh` 不會自動帶起，executor 需把它接上。
