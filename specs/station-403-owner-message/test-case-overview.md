## 我（撰寫者）不確定的地方

這些不改變要檢查什麼，所以不擋「合約已確認」，但請維護者看一眼：

1. 平台還有第三種會觸發「這個代理屬於另一位使用者」的情況：舊的、沒有指定使用者的 token 去報到一個已有擁有者的代理（`agents.py:80-81`，`test_owner_tokens.py` TC-009 起）。計畫的擁有者不符範例句寫「你的 token 是用另一位使用者的身分做的」，對這種舊 token 不完全準確（它是沒有使用者）。要不要讓措辭改成中性一點（例如「這個 token 的使用者和代理的擁有者不是同一位」）？測試只比對「另一位使用者」與 `--user`，兩種措辭都過。
2. 「下一步」我用 `--user`／`--name` 當錨點來自動檢查，是對照計畫三句要點裡的下一步；措辭若換成不含這兩個字、但意思對的話，會被判紅。你是否接受這個限制？
3. TC-028、TC-029、TC-031、TC-032、TC-033、TC-035 沒有 `docs/TESTING.md` 的步驟（計畫禁止改 docs），改由閱卷者直接看 git diff 與 ledger。你是否同意這樣算「手動」？
4. 三句話是否夠白話，是主觀判斷，已列在下方，不在 TC 裡。
