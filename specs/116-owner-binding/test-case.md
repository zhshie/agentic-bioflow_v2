# 測試案例：116 每個人只看到、也只用得到自己的運算環境、代理、run 和上傳資料夾

**規格**：`specs/116-owner-binding/plan.md`（本功能沒有獨立的 spec.md，計畫即唯一來源；維護者的話是計畫開頭「給維護者」三句）　**總覽**：`test-case-overview.md`

名詞先講白：
- **運算環境**（compute env）＝一個「跑在哪裡」的設定；**代理**（agent）＝站台上替平台做事的程式；**run**＝一次分析；**上傳資料夾**＝每人在平台上自己的檔案區 `<uploads_root>/<名字>`。
- **A、B**＝平台上兩個不同的使用者。**擁有者**＝一筆資料屬於誰（資料庫欄位 `owner_user_id`／`user_id`）。**沒有擁有者（NULL）**＝舊資料，只有本機終端機能用。
- **「找不到」的字句**＝別人的東西、沒人擁有的東西、不存在的東西，三者回的是同一句話，看不出它存在（只有回報的名字不同）。
- **本機終端機／stdio**＝在平台那台機器上直接打指令，或本機程式接 MCP；沒有「呼叫者」，行為跟現在一樣，什麼都看得到。
- **HTTP／網頁**＝透過網路登入的使用者，一定有呼叫者。

類型只有三種：

- **功能**：規格說要做到的事，正常情況下做到了。
- **例外**：出錯、缺東西、使用者做了不該做的事時，系統怎麼反應（拒絕、提示、停下）。
- **不在範圍**：規格明講這次不做的事；測試確認它真的沒做，或會明白說「這個不支援」而不是悄悄亂做。

## User Story 1 — 每個人只看得到自己的東西（優先度 P1）

維護者的話（給維護者 1）：「以後每個人只看得到、也只用得到自己的運算環境、代理、run 和上傳資料夾；別人的東西對他來說是『找不到』。」

| 編號 | 對應需求 | 類型 | 前置條件 | 步驟 | 預期結果 | 驗證方式 |
|---|---|---|---|---|---|---|
| TC-001 | 給維護者 1；D2 | 功能 | A 有環境 a1，B 有環境 b1 | A 透過 HTTP（MCP 工具）列出運算環境 | 只看到 a1，沒有 b1；B 列出時只看到 b1 | 自動 |
| TC-002 | 給維護者 1；D2 | 例外 | 同上 | A 透過 HTTP 用名字 b1 查 B 的環境 | 得到跟查一個不存在的名字完全相同的「找不到」字句（除了回報的名字），沒有任何環境內容 | 自動 |
| TC-003 | 給維護者 1；D2 | 功能 | A 有代理 ag-a，B 有代理 ag-b | A 透過 HTTP 列出代理 | 只看到 ag-a，沒有 ag-b；B 列出時只看到 ag-b | 自動 |
| TC-004 | 給維護者 1；D3 | 功能 | A 送出過 run r-a，B 送出過 run r-b（各自的 `launches` 紀錄都記了送出者） | A 透過 HTTP 列出 run | 只看到 r-a，沒有 r-b；B 列出時只看到 r-b | 自動 |
| TC-005 | 給維護者 1；D3 | 例外 | 同上 | A 透過 HTTP 用名字 r-b 查 B 的 run | 得到跟查一個不存在的 run 完全相同的「找不到」字句，沒有任何 run 內容 | 自動 |
| TC-006 | D3 | 功能 | run 名 r-x 先被 A 送出過，後來又被 B 送出（同名的最新一筆是 B） | A 和 B 各自透過 HTTP 查 r-x | 以最新一筆為準：B 查得到，A 得到「找不到」 | 自動 |
| TC-007 | D3 | 例外 | 索引裡有 run r-old，但 `launches` 裡沒有它的紀錄 | A 透過 HTTP 列出／查詢 r-old | 列表沒有它，查詢得到「找不到」 | 自動 |
| TC-008 | 給維護者 2；D3 | 例外 | 有一筆 run，其 `launches` 紀錄的送出者是空的（NULL） | 登入的 A 分別透過 HTTP、MCP-over-HTTP、網頁查看 | 三個入口都看不到這個 run（列表沒有、查詢「找不到」） | 自動 |
| TC-009 | D2；D1 | 例外 | 有一個環境與一個代理的擁有者是空的（NULL） | A 透過 HTTP 列出、並用名字查 | 列表沒有它們；用名字查得到跟不存在相同的「找不到」 | 自動 |
| TC-010 | D2 | 功能 | 同 TC-004、TC-008、TC-009 的資料全都在 | 本機終端機（CLI）與 stdio 列出環境、代理、run | 全部都看得到，包含 B 的、沒有擁有者的，行為跟改動前一樣 | 自動 |
| TC-011 | 給維護者 1；D3 | 功能 | 同 TC-004、TC-001 的資料 | B 登入網頁，看 run 列表、run 詳細頁、環境頁 | 只出現 B 自己的；開 A 的 run 詳細頁得到「找不到」 | 自動 |
| TC-012 | D2 | 例外 | 一個屬於 B 的環境、一個沒有擁有者的環境、一個不存在的名字 | A 透過 HTTP 分別用這三個名字查 | 三個回應字句相同（除了回報的名字），看不出哪個存在 | 自動 |
| TC-013 | 計畫「Not in this PR」：不做角色或全實驗室共享（010 延後） | 不在範圍 | A 與 B 在同一個實驗室（lab） | A 透過 HTTP 想看 B 的環境、代理、run | 仍然「找不到」；沒有任何共享或角色設定可以讓它看得到 | 自動 |
