## 總結

- 離線可跑（只要 testdata 有鏡像）：**31** 條
- 需要網路：**10** 條（ampliseq、differentialabundance、fetchngs、funcscan、genomeqc、pathogensurveillance、reportho、rnafusion、seqinspector、viralrecon）
- 需要 GPU：**0** 條（所有 `gpu` profile 都是選用，`test` 不載入；見下方「共通觀察」）
- 不確定：**3** 條（mcmicro、molkart、sopa）
- 「離線可跑」不等於「直接能跑」：test 的 URL 大多要逐一改成本地路徑，且許多 samplesheet 內容本身寫死 https 網址（見「共通觀察」）。
- 最大共同障礙：input 與參考檔的 https 網址不只在 `-profile test` 的參數裡，也寫死在 samplesheet 內容和 `tc` 內；只鏡像 `pipelines_testdata_base_path` 不夠。
- 次要共同障礙：啟動時從網路抓 `custom_config_base`、`nf-schema`／`nf-validation` plugin（見「共通觀察」）。

## 共通觀察（各列不再重複）

1. **GPU 都是選用**：標準 `gpu` profile 只加 `--gpus all` 與 `accelerator`，且需 `workflow.profile.contains('gpu')`（例：ampliseq `conf/base.config:73-74`、`nf.config:313-314`）。沒有任何一條的 `test` 載入它。特例見表內。
2. **容器引擎**：在這 44 條的 `*.nf`／`*.config`／`*.json`／`*.md` 中用「only supports docker／requires docker」類字串搜尋，**查不到** docker-only 限制（搜尋範圍不含 docs／tests）。只查到「不支援 conda」：pixelator `subworkflows/local/utils_nfcore_pixelator_pipeline/main.nf:48`、rnafusion `main.nf:84`（僅 ctatsplicing）、demultiplex 的 bclconvert／bcl2fastq 等模組。叢集用 singularity／apptainer 預期沒問題，但未實跑驗證。
3. **`custom_config_base` 啟動時 includeConfig**：多數管線寫成 `includeConfig params.custom_config_base && (!System.getenv('NXF_OFFLINE') || ...) ? ... : "/dev/null"`（例：viralrecon `nf.config:258`），設 `NXF_OFFLINE=true` 即略過；crisprseq `nf.config:207`、methylong `nf.config:10` 只看 `NXF_OFFLINE`；atacseq `nf.config:121-127`、chipseq、cutandrun、hgtseq、hic、nanoseq、rnasplice 用 `try { includeConfig ... } catch`（atacseq 已讀到 `nf.config:121-127`，其餘六條只確認 `includeConfig "${params.custom_config_base}/nfcore_custom.config"` 的行，try 包覆未逐一展開，標為「未逐條驗證」）。
4. **Plugin**：每條 `nf.config` 的 `plugins {}` 內有 `nf-schema@x` 或 `nf-validation@x`（例：ampliseq `nf.config:453` `nf-schema@2.7.2`、atacseq `nf.config:240` `nf-validation`、chipseq `nf.config:242` `nf-validation@1.1.3`）。hgtseq、hic 的 `nextflow.config` 內沒有 `plugins` 區塊（grep 無結果）。Nextflow 啟動時若本機沒有該 plugin 就會連網下載；叢集是否已預裝，本報告查不到。
5. **samplesheet 內容寫死 https**：下列管線的 `input` 指向本地檔，但檔內是網址，鏡像時要改檔內容：hic `assets/samplesheet.csv:2`（github.com/raw）、methylseq `assets/samplesheet.csv:2-3`、sarek `tests/csv/3.0/fastq_single.csv:2`、rnavar `tests/csv/1.0/fastq_single.csv:2`、createpanelrefs `tests/csv/1.0.0/bam.csv:2-3`、mcmicro `assets/samplesheet-test.csv:2`、spatialaxe `assets/samplesheet.csv:2`、rnafusion `tests/csv/fastq.csv:2`。遠端 `input` 的內容（rnaseq、atacseq…）在 test-datasets repo，本報告沒逐一讀，不假設其內容。
6. **`igenomes_base` 預設是 `s3://ngi-igenomes/igenomes/`**（例：rnaseq `nf.config:28`）。只有 test 設了 `genome` 又沒覆寫 `igenomes_base` 的才會碰到（seqinspector 是；createpanelrefs、sarek、rnavar 在 `tc` 內已把 `igenomes_base` 指到 raw.githubusercontent）。
