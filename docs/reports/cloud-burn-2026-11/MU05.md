## Findings

- F1 (P2, tier B): the access-control core is only partly pinned. The auth gate itself (M32 removed gate, M29 OAuth token, M35/M36 cross-user session, M40 caller scope) is well covered, but the unauthenticated metadata exception (M25, M27: any path or method answered without a token), the fail-closed `except` (M31), and unknown-session 404 (M33) are not. Fix: add the tests above; no product change.
- F2 (P2, tier B): the in-memory session table (M37, M46, M47, M48, M42, M50) has no test on its size cap, eviction order, recency, failure handling or DELETE. A token holder can open sessions to grow it; the cap is the only defence.
