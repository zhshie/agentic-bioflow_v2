**agentic-bioflow** — a Claude Code plugin that runs Nextflow / nf-core pipelines through Seqera Platform on your cluster. Platform submits work, tracks its state, and collects reports; this only adds what Platform cannot reach on a firewalled cluster.

**Five commands**

- `setup` — prepare or repair this cluster's link to Platform
- `launch` — set up and submit an analysis: pipeline, parameters, go
- `runs` — check on, debug, or deliver a pipeline run
- `downstream` — turn a SUCCEEDED run's outputs into figures or further analysis
- `finish` — assemble a project into something that can be sent out

**Analysis flow** (one "project" ties all five together)

`setup` prepare → `launch` submit → `runs` watch → `downstream` figures → `finish` package

A project holds: the raw data, every run made from it, the analysis written on those runs, and the package built from that analysis.
