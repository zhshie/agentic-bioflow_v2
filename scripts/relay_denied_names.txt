# Names this deployment's own relay allowlist (scripts/egress_allow.sh) refuses
# as "a specific domain" (#45). Read by scripts/egress_allow.sh and by
# scripts/nf_relay.py, so the two cannot disagree; it travels with scripts/.
#
#   exact <name>   refuse exactly this name. Names under it are fine: a public
#                  suffix or a shared hosting domain is not one host, but
#                  bbc.co.uk or user.github.io is.
#   tree  <name>   refuse this name and everything under it: wildcard-DNS
#                  services (any name under them resolves to whatever address
#                  the name spells), tunnel services, and names that only mean
#                  something inside one network.
#
# This is a short list of the common cases, not the Public Suffix List, and it
# cannot be complete. The relay's own check - an extra domain that resolves to
# a loopback, private or link-local address is refused at connect - is what
# holds when a name is not on it.
